# SQUAD 2033
Phone-first real-time squad action RPG. v4 = real 3D (three.js 0.170, vendored).
Play: https://mattthelf-ui.github.io/squad2033/
- models/: approved .glb models (from /workspace/models/squad2033)
- icons/hud-icons.png: Inky HUD v2 icons (rendered from hud_v2.py)
- src/a..e.js are concatenated into game.js: `cat src/a.js src/b.js src/c.js src/d.js src/e.js > game.js`
