# SQUAD 2033 — v6

2D isometric squad tactics for phones (portrait). Jagged Alliance 2-style real-time exploring that drops into turn-based AP combat on contact, with a minimal Ghost Recon-style HUD. Plain canvas 2D, no build step.

- Squad select: 4 of 7 classes (Assault, Heavy, Sniper, Scout/Demo, Tech, Leader, Radio Op) × race (Human / Robot / Grey).
- One 40×40 iso map: collaborator building (W), Nordic outpost (E), patrol, Sovereign compound (N).
- Hardcore: downed soldiers bleed out in 3 rounds unless a Tech stabilizes them; stabilized = wounded (sit out next mission); dead = permadeath (localStorage `sq2033_v6`).
- Art: Vex's approved JA2 pixel sprites (1x atlases, nearest-neighbour) in `assets/`.

The 3D v4/v5 build lives in git history.
